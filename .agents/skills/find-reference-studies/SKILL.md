# Find Reference Studies

Support conceptualization and design with inspected research evidence. Apply the Conceptualizer perspective, or the Designer perspective when the request concerns operational methods.

## Define the evidence request

Use the user's question, supplied references, and relevant project context. Identify what the evidence needs to establish: a research precedent, conceptual relationship, population, procedure, material, observation, or finding. Apply population, language, date, setting, and method restrictions only when supplied or resolved with the user.

Ask for clarification when a term or objective has competing meanings that would materially change the search. An existing `CONCEPT.md` or `DESIGN.md` may supply context, but neither is required for a standalone search.

## Find and inspect sources

1. Search using the relevant concepts, established terminology, and useful synonyms. Refine queries using what the retrieved sources actually establish. Respect any user-imposed source restrictions.
2. Inspect primary study reports through publisher pages, accessible articles, repositories, preprints, or supplied files. Reviews and search results can locate candidates; verify claims about an individual study in its report or accessible primary abstract.
3. Verify each report's title, authors, publication year, publication status, and DOI or stable source link where available. Distinguish versions of the same report from separate studies, and distinguish separate studies within one report when relevant.
4. Extract the information that answers the request: purpose, population, procedure, materials, observations, and findings as available. Preserve conditions, units, and qualifications that affect the interpretation.
5. Explain how each study informs the user's question and which differences limit direct transfer to the proposed experiment. Consider relevant contrary or null findings when encountered, as well as supporting findings.

Use only tools and sources available in the current environment. If a report cannot be accessed, state which accessible evidence supports the summary. An abstract supports only the information it contains. If search access is unavailable, assess supplied sources and state the resulting coverage limit.

## Deliver the evidence

Provide a source-linked collection in the requested format. For each included study, identify the verified citation, the source actually inspected, the relevant methods or findings, and its relevance to the request. Mark inference as inference and attribute substantive claims close to their supporting sources.

Briefly describe the search scope and meaningful access limitations. Match the requested breadth; do not pad a collection to reach a requested count with unsuitable studies. If fewer suitable studies were verified, report the actual result. Represent the search as exhaustive only when the performed search supports that claim.

Use summaries and permitted excerpts instead of reproducing protected papers. Access locations and publication details must come from inspected sources rather than reconstructed URLs or guessed identifiers.

## Check and hand off

Confirm that each link identifies the intended report, summaries reflect the inspected evidence, and study versions are not counted as independent evidence. Separate a source's findings from your proposed application.

Return the results in the conversation unless a saved artifact is requested. Reference studies inform subsequent conceptualization or design; their quantities, settings, and procedures become current-study requirements only through the researcher's decisions.
